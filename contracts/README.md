# Analytics API contract v1

Canonical machine contract: `analytics.openapi.json`, exported offline with
`APP_ENV=test PYTHONPATH=. python scripts/export-analytics-contract.py`.
`APP_ENV=test` deliberately skips `.env`; production OpenAPI remains private.
The frontend validates the same shapes with Zod. Report proportions/conversion
are ratios 0..1; metric delta_percent is signed fractional change.

Auth is same-origin: GET `/api/v1/admin/auth/csrf` returns csrf_token and sets a
10-minute HttpOnly bootstrap cookie. POST `/login` accepts username/password,
requires exact allowed Origin and X-CSRF-Token matching that cookie. Success sets
host-only HttpOnly cobalt_admin (Path=/api/v1/admin, SameSite=Lax, Secure in
production), deletes bootstrap cookie and returns username + session csrf_token.
GET `/me` returns username + csrf_token; POST `/logout` needs the session token
header and Origin and revokes the server session. Every admin response is no-store.
Credentials are never stored in localStorage. Mutation Origin is compared against
ADMIN_ORIGINS, not client-controlled Host/forwarded headers.

Events: text/plain JSON or application/json, schema_version=1, <=20 events/32KiB.
Retries reuse event_id. Accepted and duplicate counts reflect committed rows;
conflicting payload is 409 and rolls back the full batch. Known bots are ignored
with ignored count. Payload canonicalization includes entry_context. Timestamps
are limited to previous 24h/next 5m; entry_context is provisional, attribution is
confirmed only from page_view. First accepted chronological page_view wins by
(occurred_at,event_id), independent of concurrent arrival. Country is that view's
trusted edge country. Clicks without a view remain unknown, never guessed.

Snapshot reports use a single READ ONLY REPEATABLE READ PostgreSQL transaction.
from/to dates define [from,to) in the requested IANA zone. Default zone is
STATS_TIMEZONE. Country/source filters refer to entry attribution; locale refers
to the event language, including case events. Unknown country is `unknown` in query
and null in rows. Default period=30 calendar days including partial current day.
Current/future incomplete day and missing historical coverage are disclosed.
Null metric means unavailable; 0 means measured zero. Previous period delta is
null when previous coverage is incomplete; session deltas also check session
coverage. Distinct counts are recomputed for the whole interval, never summed.

The funnel links case_open.navigation_id to the destination page_view.navigation_id
within 10 minutes, then outbound page_view_id with increasing sequence/time.
New-tab destination sessions may differ. Distinct origin-session identity is used
within one case. With no session_id the funnel uses event identity and must not be
labelled session conversion. The case conversion uses distinct session_id for
viewed-case pairs with a matching later outbound click on the same page_view.
It never claims the destination website actually loaded.

Case manifest is generated by the frontend from actual case content and installed
here as `cases.json` before publishing new case IDs. Do not remove historical IDs.
Allowed case paths derive from RU/EN + id; outbound link_id=project_primary.
Changes to the contract require coordinated frontend schema/fixture review.
